# FALCON-RX dashboard

Client-only React + TypeScript + Tailwind demo app. See the [repository root README](../README.md)
for project context, [`docs/DEMO.md`](../docs/DEMO.md) for a page-by-page walkthrough, and
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for why this app has no backend.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run test
npm run lint
```
